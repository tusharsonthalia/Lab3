# Figure captions

- fig acc_vs_sparsity.png: 3 panels (MLP, CNN, GCN). x: achieved sparsity of eligible weights (fraction zero, -); y: test accuracy (-). One line per method (color = method): dashed = post_prune, solid = post_finetune, seed-0 pilot (results/pilot_summary.csv, phase=pilot rows). Open P markers: confirmatory points, mean +/- sample std of test_acc over seeds 1-3 (results/confirm_summary.csv, stage=post_finetune). Horizontal reference lines (labeled in the shared legend, not on the plot): black = dense seed-0 test acc, gray = dense seed-0 val acc (results/baselines.md, Part A train seed-0); dotted black = dense_ft seed-0 (pilot). Source: results/pilot_summary.csv, results/confirm_summary.csv, results/baselines.md.
- fig latency_vs_accuracy.png: 3 panels (MLP, CNN, GCN). x: median forward latency of each runtime path, batch 256 for MLP/CNN, full graph for GCN (ms, log scale), from the per-path timing blocks of results/pilot_summary.csv (phase=pilot, stage=post_finetune, seed-0: {path}_batch_256_median_ms / {path}_full_graph_median_ms); y: post_finetune test accuracy (-). One hollow marker per arm for the dense_zeros path and one filled marker for the compact path; marker shape = method (o s1, s s2, ^ s3, D s4) — 32 points per panel. Black star: dense seed-0 (results/baselines.md, Part A bench seed-0). Source: results/pilot_summary.csv, results/baselines.md.
- fig size_vs_sparsity.png: 3 panels (MLP, CNN, GCN). x: achieved sparsity of eligible weights (fraction zero, -); y: bytes on disk (log scale). One series per method (color = method) and artifact type (line style = artifact): solid = dense_zeros path (dense_bytes, zeros still stored), dashed = gzip-9 of the dense state_dict (gzip_bytes), dash-dot = compact artifact (compressed_bytes; S2 rebuilt dense / S1,S3 CSR / S4 packed N:M). Black line: dense on-disk bytes (results/baselines.md, Part A bench seed-0). All byte values > 1000 B (asserted). Source: results/pilot_summary.csv (phase=pilot rows: dense_bytes / gzip_bytes / compressed_bytes) and results/baselines.md.

Bytes and latency on log scale with plain-number ticks; no shared legend (x tick labels name the conditions). Source: results/runs.jsonl, part=C, phase=factorial, status=ok, python 3.12 (C2 run).

- fig partC_precision_frac_macs.png: 3 panels (MLP, CNN, GCN). x: format; y: fraction of total forward MACs performed in reduced precision (-). For half formats all ops are reduced (1.0); for INT8 the fraction is the qnnpack-quantized ops (1.0 for MLP, 1.0 for GCN projections, 0.5 for CNN where Conv2d stays fp32); INT4 simulated is 0.0 (fp32 dequant inside timed region). Source: results/runs.jsonl, part=C, phase=precision, status=ok (frac_macs_reduced_precision, per_layer).
